# Cloudflare 実務学習ガイド

Cloudflareを「管理画面の設定項目」ではなく、DNS・通信経路・セキュリティ・アプリケーション実行・データ基盤をまたぐ設計として学ぶ、日本語の実践ガイドです。

公開サイト: [Cloudflare 実務学習ガイド](https://ayutamondo.github.io/cloudflare-learning-guide/)

## はじめて読む方へ

まずは [はじめに・学習方法](guide/getting-started.md) を読んでください。必要な環境、学習の順番、各章で確認することを説明しています。

ブラウザで読む場合は、公開サイトから進めると、常時表示される目次を使って章を移動できます。

- 基礎から始める: [第1章　Cloudflareの全体アーキテクチャ](guide/01-architecture.md)
- DNS・TLS・オリジン保護を学ぶ: [第2章](guide/02-dns-tls-origin.md)
- 実際に手を動かす: [第13章　総合ハンズオン](guide/13-hands-on.md)
- 根拠を確認する: [公式ソース索引](reference/source-index.md)

## このガイドで身につくこと

- 1つのリクエストが利用者からCloudflare、オリジンへ届く経路を説明できる
- DNS・TLS・キャッシュ・WAF・Workersを、目的に応じて組み合わせられる
- 設定だけで終わらず、レスポンス・ログ・ブラウザで結果を確認できる
- 小規模なWebサービスを題材に、公開前の設計判断と運用を一通り試せる

各章は「読む → 試す → 確認する」の順に進めます。コマンドや設定例を使う際は、必ず検証用のドメイン・アカウントから始めてください。

## リポジトリの構成

```text
.
├── guide/                 # 学習本文（導入 + 全13章）
├── reference/             # 一次情報である公式ドキュメントの索引
├── assets/
│   ├── images/            # サイトのキービジュアル・図解用の画像
│   │   ├── hero/           # トップページ用のキービジュアル
│   │   └── figures/        # 本文で使うスライド型の図解画像
│   ├── diagrams/          # 既存の技術図。画像版へ段階的に移行中
│   ├── site.css           # PC・スマホ共通の表示スタイル
│   └── diagram-theme.js   # 既存図の表示補助
├── _layouts/              # GitHub Pages（Jekyll）の共通レイアウト
├── .github/workflows/     # GitHub Pagesへの公開ワークフロー
├── index.md               # 公開サイトのトップページ
├── _config.yml            # Jekyllの設定
└── README.md               # このリポジトリの入口（本ファイル）
```

## 編集・公開の流れ

1. 本文は `guide/`、根拠リンクは `reference/` を編集します。
2. 図やキービジュアルは `assets/images/` に置きます。
3. 変更前に、実在する認証情報・個人情報・顧客情報を含めていないことを確認します。
4. `main` にpushすると、GitHub ActionsがGitHub Pagesへ公開します。

## 更新の基準

内容・デザインともに、次の基準を満たすことを目標にしています。

- 初学者が用語を追えること
- 実行手順と確認方法が対応していること
- PCとスマホのどちらでも目次と本文を参照しやすいこと
- 図は装飾ではなく、判断や通信経路を理解する助けになること
- 料金・仕様・上限など変動する情報は、Cloudflare公式ドキュメントで確認すること
