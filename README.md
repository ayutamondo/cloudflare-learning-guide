# Cloudflare 実務学習ガイド

Cloudflareを、DNS・ネットワーク・セキュリティ・アプリ実行基盤・データ基盤まで、一続きの設計として学ぶための日本語ガイドです。

公開サイト: [Cloudflare 実務学習ガイド](https://ayutamondo.github.io/cloudflare-learning-guide/)

## このリポジトリでできること

- 13章の教材を、基礎から総合ハンズオンまで順に学べます。
- Cloudflareの製品名だけでなく、どの通信層で何を解決するかを理解できます。
- 各章の図、コマンド、確認方法を使い、検証環境で実際に試せます。

## 読み始める場所

学習の進め方と必要な環境は [はじめに](guide/getting-started.md) を参照してください。ブラウザで読む場合は、上記の公開サイトが最も見やすい入口です。

## ディレクトリ構成

```text
guide/       13章の教材本文と学習の進め方
reference/   公式ドキュメントなどの参照情報
assets/      サイトのスタイル、JavaScript、図解SVG/PNG
_layouts/    GitHub Pages用のページレイアウト
.agents/     教材を継続的に改善するためのCodexスキル
.codex/      Codexの担当設定
```

## 更新時の方針

教材を更新する場合は、初学者が「読む → 試す → 確認する」まで進めるかを確認してください。料金、製品仕様、制限など変わりやすい情報はCloudflare公式ドキュメントを一次情報として確認します。
